# Sticker asset sources

Both files here are from [openclipart.org](https://openclipart.org), which releases every
submission into the public domain (CC0) — free to use, modify and redistribute with no
attribution required. They were recolored to this app's own palette; nothing else was changed.

- `hibiscus.svg` — from https://openclipart.org/detail/226922/hibiscus
- `satin-bow.svg` — from https://openclipart.org/detail/170156/pink-bow
- `butterfly.svg` — from https://openclipart.org/detail/190433/simple-butterfly
- `daisy.svg` — from https://openclipart.org/detail/183948/daisy
- `satin-bow-pink.svg` — recoloured from https://openclipart.org/detail/170156/pink-bow (CC0)
- `silver-star.svg` — from https://openclipart.org/detail/168140/silver-star (CC0)
- `hibiscus-muted.svg` — the hibiscus recoloured to dusty tones (derived from `hibiscus.svg`, CC0)
- `butterfly-tan.svg` — the butterfly recoloured to tan (derived from `butterfly.svg`, CC0)
