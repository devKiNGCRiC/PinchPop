<objective>
Commit the two pipeline configuration files this phase depends on: the Vercel SPA catch-all rewrite
that makes client-side routes survive direct navigation, and the GitHub Actions workflow that gates
`main` on lint + typecheck + build.

Purpose: DEPLOY-02 fails silently without a committed `vercel.json` — 01-RESEARCH.md Pitfall 2
documents that Vite's dev server has built-in SPA fallback, so local testing "works" while
production 404s on refresh. And D-08's branch-protection task (plan 01-06) cannot name a required
status check until this workflow has actually run once and registered its check context.

Output: `vercel.json` and `.github/workflows/ci.yml`, both verified against a local dry-run of the
exact CI command sequence.

Sequenced after plan 01-02 rather than in parallel with it: Task 3 runs `npm ci`, which deletes
and reinstalls `node_modules` wholesale. Any plan installing packages or running a build at the same
moment would see a half-populated tree, so no other plan may execute concurrently with this one.
</objective>
